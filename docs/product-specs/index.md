# 产品规格说明书

## 项目概述

基于 YOLO11 的**手机使用检测系统**（**已上线运行**，非演示稿），提供图片上传 → 目标检测 → 统计报告的一条龙服务。

> **当前口径（2026-10-02）**：检测类别为 `in_hand`（手持手机）/ `on_ear`（贴耳手机）——「正在被使用的手机」，
> **不输出"人"这一类**。
> **线上形态**：纯前端静态站（浏览器内推理，图片不上传服务器）；**本地形态**：Streamlit 三栏界面。
> **生产指标**：真实负样本误报率 **1.3%**（conf≥0.5）、Precision **0.8251**（conf=0.50）。

## 核心功能列表

### F1：图片上传与检测

- **描述**：用户上传图片（JPG/PNG），系统自动检测图中**正在被使用的手机**：
  **手持（`in_hand`）** 与 **贴耳（`on_ear`）** 两种使用状态。
- **用户场景**：上传含人物使用手机的照片 → 系统框出手机位置（**近景有效**）。
- **⚠️ 已知限制**：教室/走廊等远距离监控视角下的小手机检不出（尺度/域差异，实测提高推理分辨率无效）；**不会圈出整个人**（数据只标了手机本体）。
- **验收标准**：
  - 支持上传 JPG、PNG 格式图片
  - 检测耗时 < 3 秒（CPU）/ < 0.5 秒（GPU）
  - 检测框正确绘制在图片上，不同类别用不同颜色区分
  - 未检测到目标时显示提示信息

### F2：模型切换

- **描述**：用户可在 YOLO11n (nano)、YOLO11s (small)、YOLO11m (medium) 之间切换模型。
- **用户场景**：在精度要求高的场景选 medium，在快速预览时选 nano。
- **验收标准**：
  - 切换模型后能正常加载并检测
  - 首次加载自动下载预训练权重（如本地无训练好的权重）

### F3：置信度阈值调节

- **描述**：通过滑块调节检测置信度阈值（0.05 - 0.95），过滤低置信度结果。
- **用户场景**：想减少误检时提高阈值，想发现所有可能时降低阈值。
- **验收标准**：
  - 滑块值变化后重新检测，检测数量随阈值变化
  - 默认值为 0.25；**生产建议 0.50**（Precision 0.8251 / Recall 0.3520，见最终报告第 11 节）

### F4：检测统计报告

- **描述**：自动生成检测统计报告，包含总检测数、平均置信度、各类别计数、置信度分布柱状图。
- **用户场景**：管理人员上传一批图片后查看整体手机使用情况。
- **验收标准**：
  - 报告包含：总检测数、各类别数量、各类别平均置信度
  - 柱状图正确反映类别分布
  - 检测明细表格显示每个框的完整信息

### F5：报告导出

- **描述**：将检测报告导出为 Markdown 文件下载。
- **验收标准**：
  - 点击下载按钮后生成 .md 文件
  - 包含类别统计表格和检测明细表格
  - 文件名格式：`检测报告_{图片名}.md`

### F6：多实验对比

- **描述**：提供至少 3 组训练实验（不同模型大小 / 超参数），对比 mAP、Precision、Recall。
- **验收标准**：
  - experiments/ 目录下至少 3 个子目录
  - 每个子目录包含 config.yaml、metrics.json、training_curves.png
  - 能在最终报告中展示对比表格
