# 重训方案（exp6）：口径调整为「手机使用状态检测」

> 起因：2026-10-01 达铭在线上 Demo 实际使用时报「经常出现把人脸检测为手机的情况」。
> 排查结论（错误 #015/#016）：**旧模型的失败源于训练标注污染**——大量图片把「头部/人脸」
> 标成了 `cellphone`，模型忠实学会了"人脸=手机"。且污染覆盖全部尺寸档、来源不可追溯，
> **22,879 张重组数据集整体不可用**，无法通过过滤抢救。
>
> 达铭 2026-10-01 批准：**调整项目口径并重训**，且「数据集保存在本地，不要上传到云端」。

---

## 1. 口径变更（需同步到 final-report / 网页版 / 简历）

| | 旧口径 | 新口径 |
|:--|:--|:--|
| 类别 | `People using cellphone`（人）+ `cellphone`（手机） | `in_hand`（手持手机）+ `on_ear`（手机贴耳） |
| 语义 | "正在用手机的人" | "**正在被使用的手机**" |
| 数据来源 | 来源不明的 4 数据集合并（已证不可用） | COCO 派生 + 增广（已逐项核验） |

**为什么必须改**：新数据只标注**手机本身，没有人的框**，因此原任务的「人」这一类无法完成。
`in_hand` / `on_ear` 覆盖的正是"使用中"的两种典型姿态，可完整支撑"手机使用检测"。

**诚实声明（写进报告与网页版）**：本项目现在检测的是**使用中的手机**，不再输出"人"这一类的框。

## 2. 数据

### 采用
- **`手机数据集/phone_usage_dataset`（原始）**：23,930 图 / 42,689 框
- **`手机数据集/phone_usage_split`（重切后，本项目生成）**：train 16,752 / val 3,589 / test 3,589
  - 用 `src/data/resplit_by_source.py` 生成；图片为**硬链接**，不占额外磁盘
  - 分组规则：增广图与其源图同组；同一视频所有帧同组；同组只进一个 split

### 已完成的核验（2026-10-01）
| 项 | 方法 | 结果 |
|:--|:--|:--|
| 框是否画在手机上 | 按框裁片 + 留边 + 放大 220px 排网格，逐片核对 | `in_hand` 24 片、`on_ear` 24 片**全部扣在手机上**，无一片扣脸 |
| 框尺寸是否合理 | 统计边长分布 | 中位 **0.052**（旧污染集 0.24；已知干净的 Smart School v5 为 0.037） |
| 负样本是否真为负 | 抽查 500 张空标注 | **500/500 为空**，与命名一致 |
| 泄漏是否消除 | 跨 split 源组交集 | **train∩val = train∩test = val∩test = 0** |
| 泄漏量变化 | dhash 近重复（val/test 各抽 3000） | val 7.0% → 2.7%、test 13.9% → 2.5% |
| 复位检探针是否有鉴别力 | ①同源对 ②异源对 对照 | 同源中位 **0** 距（≤4bit 占 99.8%）；异源中位 **72**（≤4bit 占 **0.0%**）→ 阈值有区分度 |

> 残留的 2.5–2.7% 经查为**探针误报**：`aug_blur_*` 重度模糊后 dhash 趋同，
> 与随机异源对的距离区间（35–54）重合；且这些图的**源图本身就在同折内**，分组是正确的。
> 原 split 被劈开的 8 个视频组（vid01/02/03/06/08 等，2,645 张）已全部整组归位。

### 不采用
- **`datasets/`（9,937 图）**：框中位占图 **56.4%**、68.5% 超人头尺；其自带教程明写"适用于**分类**数据集"。丢弃。
- **`phone.v1i (1)/(2)` + `v3i`（6,674 图）**：框确在手机上，但混噪声（"TELEPHONE"电话亭招牌、显示器、饭店账单、无手机产品图），且全为近景/商品图，无"在用"语义。暂不用。
- **`phone_train_yolo/`**：是代码（191 个 .py），非数据。

### 独立定性对照
- **Smart School v5（141 张）**：教室监控、两类齐全、**已确认干净**。用作定性验收：新模型在教室图上是否还会把人脸判成手机。

## 3. 训练配置

```bash
python -m src.models.train --model yolo11s --dataset phone_usage \
    --epochs 80 --batch 16 --imgsz 640 --device 0 \
    --exp_name exp6_phone_usage_yolo11s
```

- 选 `yolo11s`：exp4 已证明 s 在精度/速度上最均衡
- `--dataset phone_usage`：需在 `train.py` / `dataset.py` 增加该数据集分支（指向 `手机数据集/phone_usage_split`）
- 类别：`['in_hand', 'on_ear']`（nc=2）

## 4. 验收标准

| 项 | 标准 | 方法 |
|:--|:--|:--|
| mAP@50 | 与数据质量相称（如实报，不设虚高目标） | ultralytics val |
| **人脸误检率** | 在无手机的教室/人物图上，`in_hand`/`on_ear` 检出数应接近 0 | 用 Smart School v5 + Demo 示例图实测 |
| 无手机图误报 | conf≥0.5 时误报图占比应显著低于旧模型的 25/40 | 同 #015 的复现方法 |
| 泄漏 | 复检脚本三项全过 | `runs/_diag/verify_resplit.py` |
