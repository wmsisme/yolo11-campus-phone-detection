这个 Demo 是怎么跑的？
  • 纯前端推理：模型导出为 ONNX，用 onnxruntime-web（WebAssembly）在你的浏览器里执行，没有后端、不需要 API Key。
  • 与 Python 端同口径：letterbox、解码、按类别 NMS 与 src/models/onnx_infer.py 一致，测试用同一批图片逐框比对（IoU ≥ 0.9）。
  • 模型：YOLO11s 在「phone-usage 数据集（COCO 派生 + 增广，约 2.4 万张）」上训练，检测手持手机（in_hand）与贴耳手机（on_ear）两类使用状态。验证集 Precision 0.825 / Recall 0.352（conf 0.50）；在 300 张真实无手机图上误报率 1.3%（旧模型同条件为 67.7%）。
  • 平台版：同一套模型的 Python/Streamlit 版支持批量与报告导出，见仓库 src/web/app.py。
